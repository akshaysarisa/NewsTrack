NewsTrack

NewsTrack is a MySQL-based database project designed to organize and manage news channels, programmes, daily broadcast schedules, transcripts, and transcript sources.

Features

Store news channel information.

Manage programmes associated with channels.

Maintain daily broadcast schedules.

Store transcripts for individual broadcasts.

Record transcript source details.

Maintain data integrity using primary keys, foreign keys, constraints, and indexes.

Database Structure

The project contains five tables:

CHANNELS

PROGRAMS

DAILY_SCHEDULE

TRANSCRIPTS

TRANSCRIPT_SOURCES

Technology Used

MySQL

SQL

InnoDB

Project Status

The five-table database schema has been successfully created and verified. Sample data insertion, functional testing, automated transcript collection, and application development are future improvements.

Project Goal

To build an organized database foundation for managing and retrieving news transcripts based on channel, programme, and broadcast date.
